# Hava Durumu Uygulaması

## Proje Hakkında
Flask ile geliştirilmiş, şehir bazlı hava durumu takip uygulaması.
Giresun Üniversitesi Bilgisayar Mühendisliği bölümü 2. sınıf öğrencisi
olarak Samsun Teknopark Yeşilmavi Yazılım stajı kapsamında geliştirilmiştir.

## Kullanılan Teknolojiler
- Python 3.13
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML, CSS, JavaScript
- wttr.in API (ücretsiz hava durumu API'si)

## Özellikler
- Şehir ekleme ve silme
- Anlık hava durumu bilgisi
- Sıcaklık, hissedilen sıcaklık, nem ve rüzgar bilgisi
- Hava durumuna göre otomatik ikon
- Birden fazla şehri aynı anda takip etme
- Şehirler veritabanına kaydediliyor

## Kullanılan API
wttr.in — kayıt gerektirmeyen, ücretsiz ve açık kaynaklı hava durumu API'si.

## Kurulum
1. Python yükle (python.org)
2. Terminale yaz: py -m pip install flask flask-sqlalchemy
3. Terminale yaz: py app.py
4. Tarayıcıda aç: http://127.0.0.1:5000
